모듈형 웹 애플리케이션 개발 플랫폼

VSCode 스타일의 UI와 플러그인 방식의 모듈 시스템을 갖춘 풀스택 웹 애플리케이션 개발 프로젝트입니다.

확장 가능한 모듈 아키텍처

.NET 9 백엔드와 Svelte 5 프론트엔드로 구성되어 있으며, 비즈니스 모듈을 독립적으로 개발하고 통합할 수 있는 구조를 목표로 합니다. Clean Architecture 패턴을 따르며, ProductManagement와 AdminManagement 샘플 모듈이 포함되어 있습니다. 각 모듈은 자체 데이터베이스 스키마와 권한 체계를 가질 수 있도록 설계되었습니다.

개발자 친화적인 UI 구조

VSCode의 레이아웃(Activity Bar, Sidebar, Editor, Panels)에서 영감을 받아 개발자에게 익숙한 인터페이스를 웹으로 구현하고 있습니다. Svelte 5의 최신 기능과 Atomic Design 패턴을 활용하여 재사용 가능한 컴포넌트 구조를 갖추고 있으며, 멀티탭과 분할 뷰 등의 기능을 지원합니다. 다크/라이트 테마와 반응형 디자인도 구현되어 있습니다.

기본적인 인증과 권한 관리

JWT 기반 인증 시스템과 역할 기반 접근 제어(RBAC)를 구현했습니다. 사용자, 역할, 권한을 관리할 수 있는 기본 기능이 포함되어 있으며, Entity Framework Core를 사용한 데이터베이스 접근과 FluentValidation을 통한 입력 검증을 적용했습니다.

개발 환경과 테스트 구성

Docker Compose를 통한 개발 환경 설정, Playwright 기반 E2E 테스트 프레임워크, 백엔드 통합 테스트(37개), TypeScript와 ESLint를 활용한 코드 품질 관리 도구가 구성되어 있습니다. Development/Test/Production 환경별 설정 분리, 다국어 지원 구조, Tailwind CSS 기반 스타일링 시스템 등 실무 프로젝트에 필요한 기본 구성을 갖추고 있습니다.

기술 스택: .NET 9 | Svelte 5 | TypeScript | Entity Framework Core | Tailwind CSS | Docker | Playwright

현재 상태: 활발히 개발 중인 프로젝트로, 핵심 기능은 구현되어 있으나 지속적으로 개선하고 있습니다.
